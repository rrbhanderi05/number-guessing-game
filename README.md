# 🎯 Number Guessing Game

A simple Python CLI game where the computer chooses a random number between **1 and 100**, and the player has **10 attempts** to guess it correctly.

---

## 🚀 Features

* Random number generated every game
* 10 chances to guess
* Hints if the guess is **too high** or **too low**
* Input validation using `try/except`
* Simple command-line gameplay

---

## 🛠 Built With

* Python 3
* `random` module

---

## ▶️ How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run the file:

```bash
python main.py
```

---

## 🎮 How to Play

* Enter a number between **1 and 100**
* You have **10 attempts**
* If your guess is wrong, the game will tell you:

  * Too High
  * Too Low
* Guess correctly before attempts run out to win.
